# Mound Project: Generative Art Emotes

This project is a generative art experiment that creates unique emotes using JavaScript and p5.js. It was designed for creative coding, experimentation, and portfolio demonstration.

## Features
- Generative art using p5.js
- Emote creation logic in `src/index.js`
- Utility and error handling in `lib/`
- Fully client-side, no backend required

## Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/quitters/lildudes.git
   ```
2. Open `index.html` in your browser to view the project.

## Project Structure
- `index.html` – Main entry point
- `style.css` – Stylesheet
- `fxhash.js`, `p5.min.js` – JavaScript libraries
- `src/` – Main generative art logic
- `lib/` – Utility scripts
